1. 이번 작업 목표

KRX 공식 거래자료의 공개 시각 문제를 해결하고, 공식 수집기에서 R14 브리지까지 실제 데이터를 전달해 검증한다.

기존 코드, 데이터, 캐시 및 이전 개발 기록은 보존한다.

2. 공식 KRX 데이터 공개 시각 확인

사용자가 제공한 KRX Open API 공식 FAQ를 통해 다음 사항을 확인했다.

- KRX Open API 거래자료는 전일 거래자료를 다음 영업일 오전 8시부터 제공한다.
- 금요일 거래자료는 다음 영업일인 월요일 오전 8시부터 조회할 수 있다.
- 2026년 11월 18일 거래자료는 11월 19일 오전 8시 이후 조회 대상이다.

기존 수집기는 당일 거래자료를 너무 일찍 요청하여 "Missing/incomplete OutBlock_1" 오류가 발생했다.

이 오류는 API 자체의 고장으로 확정할 수 없으며, 공개 전 날짜를 요청한 문제가 주요 원인으로 확인됐다.

- "exchange-calendars" 설치 단계 추가
- "XKRX" 거래일 달력 사용

- 휴장일 자동 실행 건너뛰기 처리 추가
- 수동 실행의 "target_date" 입력 기능 유지
- Python 들여쓰기 오류 수정
