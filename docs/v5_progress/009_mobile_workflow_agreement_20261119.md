## 스마트폰 표준 작업 방식
각 수정 대상 파일마다 다음 항목을 제공한다.
1. **수정 파일 다운로드** — 기존 파일명과 동일한 완성본.
2. **기존 파일 편집하기** — 해당 파일의 GitHub `edit/main/...` 바로가기.
3. **새로운 파일 업로드** — 해당 폴더의 GitHub `upload/main/...` 바로가기.
작업에 필요한 경우 기존 GitHub Actions **실행 바로가기**도 함께 제공한다.

- 사용자 스마트폰에서 다운로드 후 필요한 파일만 교체한다.
- 기존 파일 편집 링크와 새 파일 업로드 링크는 별도로 제공한다.
- 새 파일 업로드가 기존 파일의 자동 덮어쓰기를 보장하지 않으므로 GitHub의 충돌/중복 안내를 확인한다.
- 줄별 코드 편집, 불필요한 신규 Stage·워크플로, 반복 스크린샷을 피한다.
- 실제 업로드와 Actions 실행은 사용자가 수행하고, 득이는 GitHub main 반영 및 실행 결과를 검증한다.
