## 2. 향후 개발 방식 — 고정 적용
1. **프로그램 개발 1순위, 검증 2순위**. 이미 성공한 전체 시스템 재작업 금지.
2. **변경 범위만 우선 빠른 검증**. 파일 교체 커밋(push) 시 `quick-change-check`로 문법·오프라인 자체 테스트만 수행. 실시간 KRX/DART API 조회·운영 데이터 변경 금지.
3. **전체 검증은 필요한 시점 한 번만**. 신규 검증된 KRX 거래일 자료 공개 후 정기 실행 또는 사용자의 명시적 수동 실행에만 전체 파이프라인 수행. 같은 시장일·같은 입력이면 중복 실행 차단.
4. **기존 캐시·원장 보호 및 소규모 추가 조회**. OpenDART 증빙은 이전에 검증·저장된 결과를 재사용하고, 새로 필요한 기업만 작은 배치로 조회. 호출 제한/결과 상태/이어서 검증하는 구조 유지.
5. **시간 병목 해소**. #41 DART 재무대조 128기업·384 API 요청이 약 45분 소요. 이 단계의 캐시 재활용, 신규 조회 제한, 재조회 주기 제어를 우선 최적화.
6. **실제 상태별 검증**. 기능 구현·빠른 테스트·GitHub 전체 실행·실데이터 무결성 검증·운영 완료를 구분하고, 녹색 체크만으로 전체 완료라 판단하지 않는다.
7. **동결 연구기록 및 Stage27 보호**. 날짜별 정정공시 제외 기준을 다른 날짜 코호트에 소급 적용하지 않는다. 기존 KRX 70거래일, Stage27 원장, DART 재무 캐시, v4 관찰 자료를 무단 변경하지 않는다.
8. **스마트폰 기존 전달방식**. 기존 파일명 `v5-stage28-final-orchestrator.yml`을 유지한 **전체 교체 파일 1개씩** 제공. 다운로드·기존 파일 편집·새 파일 업로드·워크플로 실행 바로가기 모두 제공. ZIP·생성용 워크플로·대량 코드 복사·중복 파일/작업 최소화.
9. **시장일 및 투자 신호**. 사용자 운영 원칙에 따라 기준 종가는 전 거래일, 다음날 KST 08:30 이후 공식 수집. 휴장일 브리핑 금지. 골든크로스는 종목 선정에 사용하지 않음. 자체 계산 PER/PBR을 공식 수치로 표시 금지. 증빙 미완 시 실전 매수 신호 금지.
10. **다음 채팅에서도 유지**. 시작 시 마스터·마지막 작업기록·최근 커밋·최신 Actions 상태를 확인하고, 동일 검증을 반복하지 않는다. 종료 시 변경 내용·검증 기록·다음 과제를 저장.
