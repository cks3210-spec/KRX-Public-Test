5. 사용자 최종 개발 방향 결정

사용자는 연구용 평가와 연구 후보 기능에 추가 개발 시간을 사용하지 않고 KRX v5 최종 프로그램 완성에 집중하기로 결정했다.

이에 따라 다음 사항을 확정한다.

- 연구용 평가 추가 개발 보류
- 연구 후보 기능 추가 개발 보류
- Stage25·26 연구 기능 통합 후순위
- Stage57 실험 기능 수동 실행만 유지
- 기존 코드와 데이터는 삭제하지 않음
- 최종 프로그램에 필수적인 기능부터 개발

연구용 등급을 검증된 최종 A/B 등급으로 취급하지 않는다.

6. 핵심 개발 우선순위

1. KRX 공식 시장 데이터 자동 수집·검증·복구
2. OpenDART 재무자료 자동 수집 및 검증
3. 공식 PER/PBR 검증과 최종 A/B 등급 산출
4. 적정 매수가 및 분할매수 가격 구간 산출
5. 적극매수·분할매수·관찰·회피 판단
6. 5·10·20거래일 성과 및 실패 원인 검증
7. 전체 자동 실행·영구 저장·자동 보고
8. 전체 시장 실데이터 통합 검증

기존 KRX_V5_MASTER.md의 완성 목표 7가지는 변경하지 않는다.

7. 개발 운영 원칙

- 기존 완성 기능 최대한 재사용

- 스마트폰만으로 운영 가능한 구조 유지
